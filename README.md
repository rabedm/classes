# Classes

Interactive teaching resources for the undergraduate course ARE/ECN 115A: Economic Development at the University of California, Davis.

## Randomized Controlled Trial Lab

An interactive resource using Miguel and Kremer’s 2004 school-based deworming study to introduce potential outcomes, the counterfactual, selection bias, and random assignment.

- **[Open the RCT Lab](https://rabedm.github.io/classes/ARE-ECN-115A-Economic-Development/rct-lab/)**

## Difference-in-Differences Lab

An interactive resource using Card and Krueger’s 1994 minimum-wage study to introduce the counterfactual, parallel trends, and the two-period DiD estimator.

- **[Open the Difference-in-Differences Lab](https://rabedm.github.io/classes/ARE-ECN-115A-Economic-Development/did-lab/)**
